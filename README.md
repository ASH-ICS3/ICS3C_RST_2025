# RST 2025 - ICS3C

## **Assignment Overview**
You will create an interactive Python program that challenges the user to complete a quiz. This project will test your ability to use:

- Strings
- Variables
- Input/Output
- Arithmetic
- Selection (if/else)
- Repetition (loops)

You will also use **string manipulation** to enhance the functionality of your program.

---

## **Your Task**
Create a Python quiz game where the user answers a series of questions and earns points based on their answers. 

### **The program must include the following features:**

### **Quiz Questions and Scoring**
- Ask the user at least **5 questions** (you can choose the topic).
- Each question should:
  - Accept user input.
  - Evaluate if the answer is correct or incorrect.
- Assign points for each correct answer.
- Use arithmetic to calculate the total score.

---

### **String Manipulation**
- Include at least one question that requires the program to manipulate strings. Examples:
  - Changing case.
  - Finding substrings.
  - Reversing a string.

---

### **Selection (if/else)**
- Use conditional statements to:
  - Determine if the user's answer is correct or incorrect.
  - Provide feedback to the user (e.g., "Correct!" or "Wrong! The correct answer was X.").

---

### **Repetition (Loops)**
- Use a loop to repeat the questions until all questions are answered.
- Optionally, allow the user to **play the quiz again**.

---

### **Variables and Input/Output**
- Store the user’s name and greet them at the start of the game.
- Use variables to store:
  - Questions
  - Answers
  - The score
- Display the user’s total score at the end of the quiz.

---

### **Arithmetic**
- Include at least one question that requires the user to solve a math problem. Example:  
  - "What is 8 * 7?"

---

## **Bonus Features (Optional)**
- Add a **timer** to limit how long the user has to answer a question.
- Provide **different levels of difficulty** (e.g., easy, medium, hard).
- Save the user's **high score** and display it when they play again.
